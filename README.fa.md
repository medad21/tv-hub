# TV Hub

[English](README.md) · **فارسی** · [Deutsch](README.de.md)

یک داشبورد زنده‌ی [TradingView](https://www.tradingview.com) به‌همراه یک ربات معامله‌گر با سه حالت: **سیگنال** (فقط هشدار)، **آزمایشی** (معامله‌ی مجازی) و **واقعی** (سفارش واقعی). مدیریت ریسک کامل، موتور بک‌تست، اعتبارسنجی آماری که تا جای ممکن نمی‌گذارد خودت را گول بزنی، کنترل از تلگرام و ساخت استراتژی با کمک هوش مصنوعی (اختیاری) دارد.

> ⚠️ **سلب مسئولیت:** این پروژه برای آموزش و پژوهش است. **توصیه‌ی مالی نیست** و هیچ‌کدام از استراتژی‌هایش سودآوری تضمین‌شده ندارد. معامله می‌تواند باعث ضرر شود. بخش سفارش واقعی فقط با صرافی و کارگزار جعلی (mock) تست شده؛ پس همیشه اول روی Testnet یا حساب آزمایشی امتحان کنید.

> ℹ️ رابط داشبورد فعلاً **فارسی (راست‌به‌چپ)** است. ربات، پیام‌های تلگرام و تنظیمات به زبان شما بستگی ندارند.

## امکانات

- **داشبورد زنده** با داده‌ی TradingView، سیگنال‌ها، پوزیشن‌های باز و تب «گزارش‌گیری» (سود و زیان، نرخ برد، Profit Factor، افت سرمایه، تفکیک به نماد، خروجی CSV).
- **سه حالت:** `signal`، `paper`، `live`.
- **استراتژی‌های آماده** (اصلاح موقت با RSI، دنبال‌کردن روند، شکست سطح، برگشت شتاب)، سه ستاپ ترکیبی با رأی‌گیری، ترکیب‌ساز بدون کدنویسی، و استراتژی شخصی با JavaScript.
- **دستیار هوش مصنوعی (اختیاری):** ایده‌ات را به زبان ساده بنویس و یک استراتژی بگیر که بعد بک‌تستش می‌کنی. AI کد نمی‌نویسد؛ فقط یک ساختار قاعده‌ی بررسی‌شده را پر می‌کند.
- **مدیریت ریسک:** حد ضرر بر پایه‌ی ATR، حد سود بر پایه‌ی ریسک به ریوارد، تریلینگ استاپ، حجم معامله بر اساس ریسک، سقف هر گروه بازار، محدودیت ضرر روزانه، توقف در حداکثر افت سرمایه، فاصله‌ی زمانی بین معاملات و فیلتر روند.
- **بک‌تست** از داشبورد یا خط فرمان، با ورود روی open کندل بعد و هزینه‌ی جدا برای هر بازار.
- **آمار صادقانه:** Walk-Forward، مونت‌کارلو، بوت‌استرپ بلوکی، تعدیل برای آزمودن زیاد، یک بازه‌ی کنار گذاشته‌شده (hold-out) و دفترچه‌ی تحقیق که تعداد ایده‌های امتحان‌شده را می‌شمارد.
- **شواهد جلورونده:** نتیجه‌ی واقعی ربات را با بک‌تست همان هفته‌ها مقایسه می‌کند.
- **ورود تاریخچه‌ی بلند** از آرشیو عمومی Binance برای آمار بسیار بهتر.
- **تلگرام:** هشدار و کنترل از راه دور (`/status`، `/positions`، `/pnl`، `/close`، `/halt`، `/resume`، `/panic`).
- **مناسب موبایل:** نصب روی صفحه‌ی اصلی (PWA) و محافظت با رمز.
- **لایه‌های ایمنی:** نوشتن اتمیک فایل‌ها، تشخیص فایل خراب، استاپ سمت صرافی، بررسی تطبیق در شروع اجرا و watchdog.

## شروع سریع

پیش‌نیاز: **Node.js نسخه‌ی ۱۸ یا بالاتر** (۲۰ یا ۲۲ پیشنهاد می‌شود).

```bash
git clone <your-repo-url> tv-hub
cd tv-hub
```

- **ویندوز:** دو بار کلیک روی `start.bat`
- **مک / لینوکس:** `./start.sh`

در اولین اجرا بسته‌ها نصب می‌شوند و فایل `.env` از روی `.env.example` ساخته می‌شود. بعد **http://localhost:3000** را باز کنید.

یا دستی:

```bash
npm install
cp .env.example .env
npm start
```

حالت پیش‌فرض `MODE=signal` است که هیچ پوزیشنی باز نمی‌کند.

## داکر و اجرای ۲۴ ساعته

```bash
cp .env.example .env     # MODE و یک DASH_PASSWORD قوی را بنویسید
docker compose up -d
```

- بعد از کرش یا ری‌استارت سرور خودکار بالا می‌آید (`restart: unless-stopped`).
- اگر داده‌ی بازار ۵ دقیقه قطع شود، برنامه خودش را می‌بندد تا Docker دوباره بالا بیاورد.
- `state.json` و لاگ رویدادها در یک Docker volume می‌مانند.

**پورت ۳۰۰۰ را بدون HTTPS روی اینترنت باز نکنید.** دو راه امن: [Tailscale](https://tailscale.com) (شبکه‌ی خصوصی) یا Cloudflare Tunnel (با رمز قوی). برای دسترسی از موبایل، `HOST=0.0.0.0` و یک `DASH_PASSWORD` قوی بگذارید (در این حالت بدون رمز برنامه اصلاً بالا نمی‌آید).

## تنظیمات

همه‌چیز در `.env` است (همه‌ی گزینه‌ها در `.env.example`):

```env
MODE=signal                     # signal | paper | live
SYMBOLS=BINANCE:BTCUSDT,OANDA:XAUUSD   # EXCHANGE:TICKER، خالی = لیست پیش‌فرض ۲۵ نمادی
TIMEFRAME=60                    # 1, 5, 15, 30, 60, 240, D, W (پیش‌فرض 15)
HOST=127.0.0.1
DASH_PASSWORD=
TELEGRAM_TOKEN=
TELEGRAM_CHAT_ID=
LIVE_CONFIRM=NO                 # برای سفارش واقعی باید YES باشد
```

پیش‌فرض‌های استراتژی، ریسک و فیلترها در `config.js` هستند. تنظیماتی که از داشبورد اعمال کنید در `config.local.json` ذخیره می‌شوند. هر نمادی از TradingView که با قالب `EXCHANGE:TICKER` باشد قابل دیده‌بانی است.

## حالت‌ها

| حالت | چه می‌کند |
|---|---|
| `signal` | فقط هشدار (داشبورد و تلگرام). هر پیام استراتژی، قیمت ورود پیشنهادی، حد ضرر، حد سود و دلیل را می‌گوید. ربات فقط خرید (Long) می‌کند؛ پس سیگنال فروش یعنی «ببند»، نه «شورت باز کن». |
| `paper` | معامله‌ی مجازی با ۱۰٬۰۰۰ واحد سرمایه، همراه با کارمزد و اسلیپیج. |
| `live` | سفارش واقعی روی صرافی‌های کریپتو، سهام آمریکا (Alpaca) و فارکس/طلا (OANDA). به کلید و `LIVE_CONFIRM=YES` نیاز دارد. نمادی که کارگزارش کلید ندارد فقط سیگنال می‌دهد. |

## استراتژی‌ها

| استراتژی | ایده |
|---|---|
| اصلاح موقت (RSI) — پیش‌فرض | افت سریع و بیش‌ازحد را می‌خرد، رشد بیش‌ازحد را می‌فروشد. |
| دنبال‌کردن روند | میانگین کوتاه‌مدت از بلندمدت بالاتر برود → خرید. |
| شکست سطح | شکست بالاترین قیمت ۲۰ کندل اخیر → خرید؛ شکست پایین‌ترین → خروج. |
| برگشت شتاب (MACD) | شتاب به بالا برگردد → خرید؛ به پایین → فروش. |
| ستاپ‌های ترکیبی | خرید اصلاح در روند صعودی، شکست با تأیید شتاب، و اجماع چهار استراتژی. |

علاوه بر این می‌توانید بدون کدنویسی **ترکیب** بسازید (چند استراتژی و حداقل رأی)، استراتژی شخصی با **JavaScript** بنویسید (فایل `custom-strategies.example.js` را به `custom-strategies.user.js` کپی کنید)، یا از **دستیار AI** با کلید API خودتان استفاده کنید (Claude یا هر سرویس سازگار با OpenAI، از جمله Ollama محلی؛ کلید فقط روی سرور می‌ماند و هیچ‌وقت به مرورگر برنمی‌گردد). بدون کلید هم می‌توانید متن آماده را در هر چت‌باتی بچسبانید و پاسخ را وارد کنید.

> استراتژی‌های شخصی JavaScript در همان پردازش و بدون sandbox اجرا می‌شوند. فقط کدی را بگذارید که خودتان نوشته‌اید یا کاملاً می‌فهمید.

## مدیریت ریسک

حد ضرر بر پایه‌ی ATR (پیش‌فرض ۲×ATR)، حد سود ۱ به ۲، تریلینگ استاپ بعد از ۱R، حجم معامله از ریسک ثابت هر معامله (پیش‌فرض ۱٪ سرمایه)، سقف یک پوزیشن، سقف هر گروه بازار (کریپتو / سهام / فارکس)، کاهش خودکار ریسک روی نمادهای خیلی پرنوسان، حداکثر پوزیشن هم‌زمان، محدودیت ضرر روزانه، توقف در حداکثر افت سرمایه، فاصله‌ی زمانی بعد از هر بستن، فیلتر روند EMA100، فیلتر تأیید چند اندیکاتور، و خروج پلکانی اختیاری (فقط روی کریپتو در حالت live).

## بک‌تست و اعتبارسنجی

```bash
npm run backtest          # اجرای استراتژی فعلی روی کندل‌های تاریخی
npm run sweep             # امتحان ۲۷۰ ترکیب تنظیمات (رتبه‌بندی Train/Test)
npm run import-history -- --symbols BINANCE:BTCUSDT --tf 15,60 --from 2023-01
```

بک‌تست از همان موتور ربات زنده استفاده می‌کند، پس نتیجه‌اش رفتار واقعی را نشان می‌دهد. ورود روی **open کندل بعد** است و برای کریپتو، سهام و فارکس هزینه‌ی جدا حساب می‌شود. نتایج ممکن است از بک‌تست‌های ساده ضعیف‌تر باشند؛ این عمدی است.

یک نتیجه فقط وقتی «**قابل اتکا**» حساب می‌شود که همه‌ی این‌ها را رد کند: حداقل ۳۰ معامله، Profit Factor حداقل ۱٫۲، میانگین R مثبت، سودده بودن در حداقل ۳ از ۵ بازه‌ی Walk-Forward، احتمال ضرر پایین در مونت‌کارلو، آزمون معناداری با بوت‌استرپ بلوکی که برای تعداد ایده‌های امتحان‌شده تعدیل شده، و یک آزمون یک‌باره روی ۲۵٪ از داده که از هر تصمیمی کنار گذاشته شده بود. اگر هیچ‌چیز رد نشود، گزارش همین را می‌گوید و «بهترینِ بد» را انتخاب نمی‌کند.

## بازارها و کارگزارها

| بازار | سرویس | کلیدها |
|---|---|---|
| کریپتو (اسپات) | Binance، Bybit، OKX، KuCoin، Kraken، Coinbase، Bitget، Gate.io، MEXC (با ccxt) | `*_KEY`، `*_SECRET` (و `*_PASSPHRASE` برای OKX، KuCoin، Bitget) |
| سهام آمریکا | Alpaca (پیش‌فرض آزمایشی) | `ALPACA_KEY`، `ALPACA_SECRET` |
| فارکس و طلا | OANDA (پیش‌فرض حساب Practice) | `OANDA_TOKEN`، `OANDA_ACCOUNT_ID` |

کلید API را **فقط با دسترسی معامله و بدون برداشت** بسازید. در دسترس بودن هر سرویس به قوانین کشور شما و شرایط همان سرویس بستگی دارد.

## تلگرام

با `@BotFather` یک ربات بسازید و از پنل داشبورد یا `.env` وصلش کنید. هشدار سیگنال، پیام روشن‌شدن و قطعی، خلاصه‌ی روزانه و گزارش هفتگی شواهد می‌گیرید، و فقط از چت ثبت‌شده می‌توانید ربات را کنترل کنید: `/status`، `/positions`، `/pnl`، `/close BTCUSDT`، `/halt`، `/resume`، `/panic`. پروکسی HTTP اختیاری فقط برای تلگرام پشتیبانی می‌شود.

## قبل از معامله‌ی واقعی

1. `npm test`
2. `npm run backtest` و `npm run sweep` روی داده‌ی واقعی
3. `MODE=paper` به مدت چند هفته
4. `MODE=live` روی Testnet یا حساب آزمایشی (`EXCHANGE_TESTNET=YES`، `ALPACA_PAPER=YES`، `OANDA_PRACTICE=YES`)
5. فقط بعد از آن: کلید واقعی، سرمایه‌ی خیلی کم در `capitalUsdt` و `LIVE_CONFIRM=YES`

مجموعه‌ی تست‌ها بدون اینترنت و با صرافی و کارگزار جعلی اجرا می‌شود و منطق ریسک، کارگزارها، بک‌تست، آمار، هشدارها، پایداری، استراتژی‌های دلخواه، دستیار AI، ایمنی معامله‌ی زنده و موارد دیگر را پوشش می‌دهد.

## محدودیت‌های شناخته‌شده

- داده‌ی بازار از یک کتابخانه‌ی غیررسمی TradingView می‌آید که ممکن است با تغییر TradingView از کار بیفتد.
- حد ضرر و سود را خود برنامه پایش می‌کند؛ استاپ سمت صرافی برای کریپتو پیش‌فرض روشن است، ولی تریلینگ استاپ فقط داخل برنامه جابه‌جا می‌شود (در Alpaca و OANDA استاپ سمت کارگزار ثابت می‌ماند).
- گپ‌های قیمتی می‌توانند ضرری بیش از حد ضرر بسازند.
- ورود تاریخچه‌ی بلند فقط برای اسپات Binance است؛ سهام و فارکس به داده‌ی TradingView و آرشیو در حال رشد محلی محدودند.
- رابط داشبورد فعلاً فقط فارسی است.
